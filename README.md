# Advanced Network Traffic Analysis (Week 5 - Task 4)

## Overview
This repository contains the deliverables for **Week 5 - Task 4** of the Cyber Security Internship. The project focuses on analyzing captured network packet data (`.pcap`) using **Wireshark** and **tcpdump** to detect protocol anomalies, reconnaissance scans, Command-and-Control (C2) beaconing, and unauthorized data exfiltration.

## Repository Structure
* `docs/Network_Traffic_Analysis_Report.md` - Comprehensive packet analysis report detailing methodology, protocol breakdown, anomalies detected, and mitigation steps.
* `docs/Suspicious_Activities_Summary.md` - Focused breakdown of malicious IP flows, Wireshark display filters used, and Indicators of Compromise (IoCs).

## Tools & Protocols Analyzed
* **Analysis Tools:** Wireshark, tcpdump
* **Protocols Inspected:** TCP/IP, HTTP, DNS, ARP, SMB, SMTP
